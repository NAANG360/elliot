# Miss Minutes

An independent, mobile-first fan-made Miss Minutes-inspired assistant UI. This repository is intentionally separate from the Replit build so both versions can evolve independently.

## Run

```bash
npm install
npm run dev
```

Set `OPENAI_API_KEY` on the server when adding a real model backend. The browser never receives the key.

## Current build

- TVA-inspired animated clock character
- chat + local history
- demo reply engine when no backend is configured
- browser speech synthesis
- browser speech recognition where supported
- manually controlled memory
- settings and reduced-motion support
- installable PWA foundation
