# Project Boundaries

## Privacy

Miss Minutes is a private personal project. The repository, APKs, private model artifacts, datasets, checkpoints, memory archives and unreleased experiments are not grants to third parties.

Private means private distribution intent. It does not override third-party copyright, trademark, performer rights, licences, platform terms or ownership.

## Creator-control principle

The project's internal motto is:

> If I make the invention, I decide who gets the invention.

That is a project-distribution rule, not a claim that the creator owns things belonging to other people.

Examples:
- A phone belonging to somebody else remains their property.
- Android, Linux, libraries and third-party models retain their respective licences.
- Marvel/Loki/Miss Minutes and performer rights are not claimed as project-owned IP.
- Original code, experiments, architecture, datasets and unreleased artifacts created for this project remain private unless deliberately released.

## Voice

The application keeps the speaker behind a replaceable interface. The current build uses Android TTS.

A recognizable performer-specific voice model is not included merely because the project is private. A future performer-specific backend requires an appropriate authorization/licence or another legally sufficient basis for the intended use.

## Self-modification

Miss Minutes may evolve editable software, data, capabilities and adaptation artifacts, but the independent Guardian boundary remains outside the editable layer. Self-modification is not permission to bypass Android security, steal credentials, escape a sandbox or alter software outside the project.

## Destruction presentation

The death sequence is a visual application state. It cannot intentionally crash Android, erase the phone, corrupt storage or perform a real system failure.
